Based on the analysis, here's the remaining work organized by priority:

### **Phase 1: Team Leader (Supervisor) Workflow** 🎯 NEXT STEP

**Goal:** Allow team leaders to approve or reject student time entries.

**Tasks:**

1. **Create `supervisor.go` file** with these handlers:
   - `GetPendingTimeEntriesHandler` - Fetch all time entries with status "gesendet" (submitted)
   - `ApproveTimeEntryHandler` - Change status from "gesendet" → "bestaetigt" (approved)
   - `RejectTimeEntryHandler` - Change status from "gesendet" → "abgelehnt" (rejected)

2. **Write SQL queries** in your `.sql` files for sqlc:
   - `GetPendingTimeEntries` - SELECT entries WHERE status = 'gesendet'
   - `UpdateTimeEntryStatus` - UPDATE status and add approval/rejection comment

3. **Register routes** in `web.go`:
   ```
   /supervisor/pending-entries (GET)
   /supervisor/approve (POST)
   /supervisor/reject (POST)
   ```

4. **Add role check** - Verify user has "supervisor" role (like you did for admin)

5. **Frontend integration** - Connect `teamLeiter_ZeitGenehmigen.html` with JavaScript to call these APIs
